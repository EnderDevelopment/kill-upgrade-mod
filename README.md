# Kill Upgrade Mod

Upgrade your mace with each kill in Minecraft!

## Features

- Mace upgrade system with each kill
- Multiple mace tiers with unique effects
- Player banning feature for reaching the highest tier

## Requirements

- Minecraft 1.18.2
- Forge 40.2.0

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/kill-upgrade-mod/releases).
2. Place the mod file in your Minecraft mods folder.
3. Launch Minecraft with Forge.

## Usage

1. Craft a mace using the appropriate materials.
2. Use the mace to kill other players.
3. The mace will upgrade with each kill, providing enhanced combat capabilities.
4. If a player reaches the highest mace tier, they will be banned.

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
